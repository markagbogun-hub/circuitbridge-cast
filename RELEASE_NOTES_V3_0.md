# Castwise Audio Doctor 3.1.0 — Commercial Edition

## Product focus
Castwise Audio Doctor 3.0 is a commercial-grade QC and delivery workstation for broadcast, podcast and digital audio workflows.

## Major upgrades
- Persistent Castwise Session files for repeatable QC work.
- Compliance report export with profile, measured values, status and timestamp.
- Delivery Profile workspace and JSON export.
- Unified commercial release versioning across application and installer.
- Improved customer workflow: Open → Analyze → Review → Repair/Normalize → Verify → Report.
- Release documentation and verification package.

## Engineering note
True-peak remains explicitly labelled approximate where the analysis engine uses an approximation. Regulatory or platform compliance is not claimed unless the selected delivery specification is independently verified.
